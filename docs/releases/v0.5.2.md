# QuotaDock v0.5.2

## 更新修复

- 应用内更新器现在会在未配置 `HTTPS_PROXY` / `ALL_PROXY` 环境变量时读取 Windows“Internet 选项”的静态代理，修复浏览器可以访问 GitHub、QuotaDock 却无法获取 `latest.json` 的问题。
- 更新清单和安装包下载共用同一代理，并设置 30 秒连接超时与 60 秒无数据读取超时；慢速下载不会再被固定总时限误杀，签名验证和安全策略保持不变。
- 在 Windows 更新器退出应用前保存悬浮窗位置，避免成功安装后丢失位置状态。

## 体验优化

- 托盘菜单不再直接显示 URL 和底层网络错误；所有动态文案都会单行化并限制长度，避免菜单被撑满屏幕。
- 检查期间菜单项显示“正在检查更新…”并禁用重复操作，完成后恢复。
- 详情页新增“软件更新”卡片，展示当前版本、检查状态、下载进度和上次检查时间。
- 失败时提供“重新检查”和“浏览器下载”两条恢复路径；技术详情默认折叠，需要时可展开复制诊断。
- Release Notes 在原生安装确认框中限制长度，防止异常超长弹窗。

## 安全与兼容

- 自动更新继续使用 v0.5.0 起内置的 Ed25519 公钥验证安装包签名；代理仅改变网络路由，不会降低证书或签名校验。
- v0.5.0 / v0.5.1 在必须通过 Windows 系统代理访问 GitHub 的环境中无法自行取得本修复，需要从 Release 页面手动安装 v0.5.2 一次；后续版本即可恢复应用内更新。
- Windows 安装包暂未配置商业 Authenticode 证书，首次手动安装仍可能出现 SmartScreen 提示。

## 验证

- Rust：54 项通过、0 失败、2 项需真实外部环境的测试保持忽略。
- 前端：34 项通过，Svelte/TypeScript 检查 0 错误、0 警告。
- 生产前端构建通过；440 × 600 实际详情窗口尺寸下无横向溢出，浏览器控制台 0 错误、0 警告。
