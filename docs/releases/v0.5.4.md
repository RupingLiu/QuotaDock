# QuotaDock v0.5.4

## 更紧凑的常驻状态条

- 常驻悬浮条由 `360 × 36px` 收紧为 `260 × 36px`，仍保留 1 周额度、重置时间、数据新鲜度与菜单入口。
- 针对窄宽度重新分配文字空间，保证关键百分比和状态始终可见；在更窄的兼容宽度下优先隐藏次要的重置时间。
- 迁移旧窗口位置时保留屏幕边缘锚点，避免缩短窗口后在右侧留下明显空隙。

## 后台准备更新

- 应用启动后进行首次更新检查，之后每 6 小时周期检查；关闭“自动检查更新”后不会执行后台检查或下载。
- 发现新版本后直接在后台下载，下载完成后先使用应用内置 Ed25519 公钥验证发布签名。
- 只有签名和安装包内嵌 ProductVersion 均与更新清单一致时，才能进入“已准备”状态；旧版合法签名包不能伪装成新版本。
- 已验证安装包与清单信息使用单文件原子缓存；缓存落盘失败不会误报“已准备”，同一版本也不会被重复下载或重复提示。
- 下载完成后发送不抢焦点的 Windows 系统通知，并在详情页保留清晰的“已准备”状态。

## 安装交互

- 移除更新检查过程中的阻塞式确认对话框，自动检查、下载和验签均不打断当前工作。
- 用户在详情页主动点击“立即安装”后才启动安装器；安装期间显示独立状态并防止并发检查或重复安装。
- 网络、下载、验签和安装错误继续使用简短可恢复文案，技术详情按需展开，不把长 URL 塞入菜单。

## 安全与验证

- 下载完成并不等于可安装：更新包必须先通过签名验证、内嵌 ProductVersion 校验与最高可信版本检查，安装前还会对同一份字节重新执行这些校验。
- 发布构建继续生成 `.sig`、SHA-256 和 `latest.json`，并在 CI 中核对安装包 ProductVersion、再用内置公钥对最终安装包执行独立验签。
- Windows 安装包暂未配置商业 Authenticode 证书，首次手动下载仍可能出现 SmartScreen“未知发布者”提示；这不影响应用内 Ed25519 更新验证。
