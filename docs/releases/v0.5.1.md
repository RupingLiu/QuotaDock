# QuotaDock v0.5.1

## 修复

- 将 OpenAI 未提供的 5 小时额度窗口视为可选能力，不再错误显示“注意”。
- 兼容 v0.5.0 已持久化的 `missing-five-hour` 状态，升级后无需清除本地数据。
- 结构化 App Server 和 PTY `/status` 降级路径采用一致的额度窗口语义。

## 发布保障

- 新增手动、隔离的 GitHub Actions 签名构建流程；只有验证通过的构建资产才会用于正式 Release。
- 安装包继续使用 v0.5.0 内置公钥对应的 Ed25519 私钥签名，可由现有客户端安全升级。
- Release 继续提供安装包、Tauri `.sig`、SHA-256 文件与 `latest.json`。

## 已知说明

- 当 OpenAI 只返回周额度时，5 小时位置显示 `--`，整体状态仍为正常和新鲜。
- Windows 安装包暂未配置商业 Authenticode 证书，首次下载安装仍可能出现 SmartScreen 提示。
