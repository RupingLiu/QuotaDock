# QuotaDock v0.5.0

这是一次可靠性、信任与可控性版本。

## 主要变化

- 主查询链切换到 Codex App Server 结构化接口，PTY `/status` 仅作兼容降级。
- 更新器改为 Tauri 签名更新，使用应用内置 Ed25519 公钥验证安装包。
- 增加单实例，避免重复托盘、并发查询和状态文件竞争。
- 增加详情与设置窗口：数据来源、诊断、官方 Usage 入口、启动/更新/通知开关。
- 增加默认关闭的 20% 低额度系统通知和最多 7 天轻量趋势。
- 状态格式升级到 v3；v2 自动无损迁移，损坏恢复提示会保留到用户确认。
- 状态备份最多保留 3 份，WebView 启用最小 CSP，安装模式改为当前用户。
- 修复动态倒计时、失败吞没、窗口位置恢复、Spark 段串线、半份 PTY 输出、
  重置时间解析、Windows Rust 测试启动崩溃等问题。
- 常驻条优化为 `360 × 36px`，补齐键盘、深色、减少动画和显式状态反馈。

## 升级与兼容

- `latest.json` 同时支持 v0.2.x 自定义更新器和 v0.5.0+ Tauri 签名更新器。
- 首次运行 v0.5.0 会把本地状态从 v2 迁移到 v3，不会删除最近快照。
- 如结构化接口不可用，应用会自动尝试现有 `/status` 兼容模式。

## 安全说明

应用内自动更新包带独立 Ed25519 签名。Windows 安装器当前没有商业
Authenticode 证书，因此 SmartScreen 仍可能显示“未知发布者”。建议从本项目
GitHub Release 下载，并可使用随附 SHA-256 文件人工核验。
