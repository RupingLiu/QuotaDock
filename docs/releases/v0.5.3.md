# QuotaDock v0.5.3

## 数据口径修正

- 删除 OpenAI 当前官方数据源不再提供的 5 小时额度，1 周额度成为 QuotaDock 唯一展示、存储和告警的额度口径。
- Codex App Server 结构化查询只选择周额度窗口；PTY `/status` 降级解析也只提取周额度，不再识别、映射或保留 5 小时窗口。
- 删除 5 小时额度相关的数据模型、前后端传输字段、历史采样、趋势序列、低额度通知和自适应刷新分支。
- 删除 `missing-five-hour` 等兼容性告警与占位状态；官方没有返回已废弃窗口时，不再显示 `--`、“注意”或数据不完整提示。

## 界面收敛

- 常驻悬浮条改为单一的 1 周额度视图，为百分比、重置时间、数据新鲜度和异常状态提供更清晰的空间。
- 详情页只保留 1 周额度卡片与单条历史趋势，避免展示无法从官方数据源验证的指标。
- 窗口标题、辅助功能文本、状态说明和诊断信息统一使用周额度口径，不再向用户暴露已删除功能的名称。
- 低额度、临近重置、失败、陈旧和空数据等状态保持原有语义，但全部以周额度为唯一依据。

## 状态存储清理

- 本地状态 schema 升级到 v4；最新快照和历史记录只持久化周额度，不再写入 5 小时百分比或重置时间。
- 旧状态中的 5 小时字段不会进入 v4 运行时状态，也不会影响趋势、通知、刷新频率或健康状态判断。
- 本版本不保留未来恢复 5 小时额度的预留字段、解析器或 UI 开关；如官方数据能力发生变化，将按新的产品需求重新设计。

## 更新与安全

- v0.5.2 用户可通过已修复的代理感知更新器直接升级；更新清单与安装包继续使用同一 Windows 静态系统代理设置。
- 安装包继续使用应用内置 Ed25519 公钥验证签名，删除额度字段不会改变更新信任链、隐私边界或本地安装模式。
- Windows 安装包暂未配置商业 Authenticode 证书，首次手动下载安装仍可能出现 SmartScreen“未知发布者”提示。

## 验证范围

- 对前端、Rust 后端和发布测试执行语义残留扫描，确保运行时代码不再包含 5 小时字段、`missing-five-hour` 状态或对应显示文案。
- 覆盖结构化 App Server、PTY 降级、状态持久化、历史采样、低额度边界、通知和自适应刷新等周额度主链路测试。
- 执行前端单元测试、Svelte/TypeScript 检查和生产构建，并检查常驻悬浮条与 440 × 600 详情页的单额度布局。
- 执行 Rust 格式检查、全目标检查与测试；正式发布构建还会验证安装包 Ed25519 签名、SHA-256 和 `latest.json` 元数据。
