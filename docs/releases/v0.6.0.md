# QuotaDock v0.6.0

> 已撤回：此版本误将用户所说的 Kimi 额度实现为 Moonshot API 开放平台余额。
> 请勿安装；改用 v0.6.1。下文仅保留为历史记录。

## 多供应商余额

- 新增 DeepSeek API 开放平台余额，展示总额、赠金和充值余额，并保留官方多币种精度。
- 新增 Kimi 国内 API 开放平台可用、现金和代金券余额；不包含国际站、Kimi 会员或 Kimi Code。
- 三家独立刷新、独立错误与旧值保留；刷新全部时允许部分成功，快结果不等待慢供应商。

## 260 × 36 轮播

- 悬浮条尺寸保持 `260 × 36px`，默认仍只显示 Codex，可在详情页选择参与轮播的已配置供应商。
- 固定按 Codex → DeepSeek → Kimi 每 8 秒循环；单项不计时，hover、focus 和页面隐藏时暂停。
- 供应商标签支持鼠标与键盘手动下一项；减少动态效果模式关闭自动轮播。

## 凭据与隐私

- DeepSeek/Kimi API Key 由用户主动设置，并保存到当前用户的 Windows Credential Manager；前端不回显。
- 普通 schema v5 状态以本地明文保存额度/余额快照、配置状态和轮播选择，但不保存认证凭据、API Key、Authorization、完整响应或 PTY 原文。
- 删除连接会删除对应 Windows 凭据并移出轮播。删除普通应用数据不会删除凭据；当前卸载器也不会自动清理凭据，建议卸载前在详情页删除连接。
- 查询只访问固定官方 HTTPS endpoint，禁用重定向并限制超时和响应大小；软件内不执行充值或支付。

## 升级与兼容

- v4 状态自动迁移到 schema v5，保留 Codex 最新快照、7 天稀疏趋势、设置和窗口位置；新安装默认仅 Codex。
- DeepSeek/Kimi 未配置时显示“未配置”，不会阻塞 Codex 或计入轮播。
- 更新包继续使用应用内 Ed25519 签名、ProductVersion 和版本回放检查。Windows 安装包尚无商业 Authenticode 证书，SmartScreen 仍可能显示“未知发布者”。

## 验证边界

- 自动化测试使用脱敏 fixture、本地 HTTP server 与内存凭据库，不访问真实账户或 Windows 凭据。
- 正式发布前仍需维护者在 Windows 发布机完成真实临时账号、升级安装和签名资产冒烟，结束后立即删除测试 Key。
